<div class="banner">
<h2>Key features</h2>
</div>

<div class="prose-block" markdown>

- Stereo-matched pair with consistent response
- Modular cable system (swap between minijack and XLR)
- Compact ⌀13 mm capsule for discreet placement
- Exceptionally low self-noise (~14 dBA)
- High sensitivity (−28 dB re 1 V/Pa)
- Plug-in powered (2–10 V)

</div>

<div class="banner">
<h2>Specifications</h2>
</div>

<div class="specs" markdown>

| Parameter | Value |
|---|---|
| Transduction principle | Pre-polarized condenser (electret) |
| Directional characteristic | Omnidirectional |
| Sensitivity (free field, 1 kHz) | −28 dB ±3 dB at 1 kHz |
| Equivalent noise level (A-weighted) | ~14 dBA |
| Power supply | 2–10 V plug-in power |
| Rated output impedance | 2.4 kΩ ±30% |
| Minimum load impedance | 24 kΩ |
| Output connector | 3.5 mm jack |
| Output type | Unbalanced |
| Dimensions | 26.2 mm × ⌀13 mm |
| Cable length | 1.5 m per microphone |
| Cable diameter | 2.5 mm |
| Operating temperature | −10 °C to +55 °C |
| Storage temperature | −25 °C to +70 °C |

</div>

<div class="banner dark">
<h2>How to use Uši</h2>
</div>

<div class="prose-block" markdown>

1. Plug Uši into your recorder's "mic in" (3.5 mm minijack input)
2. Make sure that **plug-in power is on**
3. On some recorders this needs to be set up using internal menus — consult your recorder's manual
4. Set your gain to appropriate levels and enjoy!

[How to mount Uši →](../tips/mounting-usi.md)

!!! warning
    Using Uši with third-party cables is not covered under warranty. Uši XLR cables contain special circuitry to adjust phantom voltage for plug-in power voltage.

</div>
