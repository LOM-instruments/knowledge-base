<div class="banner">
<h2>Key features</h2>
</div>

<div class="prose-block" markdown>

- Phantom powered (24–48 V)
- Balanced transformer-less XLR output
- Compact ⌀13 mm capsule
- Exceptionally low self-noise (~14 dBA)
- Low output impedance (30–50 Ω)
- Compatible with all Uši series accessories

</div>

</div>

<div class="split-cell" markdown>

<div class="banner">
<h2>Specifications</h2>
</div>

<div class="specs" markdown>

| Parameter | Value |
|---|---|
| Transduction principle | Pre-polarized condenser (electret) |
| Directional characteristic | Omnidirectional |
| Sensitivity (free field, 1 kHz) | −28 dB ±3 dB at 1 kHz |
| Equivalent noise level (A-weighted) | ~14 dBA |
| Power supply | 24–48 V phantom (IEC 61938) |
| Current consumption | ~3 mA per pin |
| Rated output impedance | 30–50 Ω |
| Minimum load impedance | 1 kΩ |
| Output connector | XLR-3M |
| Output type | Balanced transformer-less floating |
| Dimensions | 26.2 mm × ⌀13 mm |
| Cable length | 1.5 m |
| Cable diameter | 2.5 mm |
| Operating temperature | −10 °C to +55 °C |
| Storage temperature | −25 °C to +70 °C |

</div>

<div class="banner dark">
<h2>How To Use Ucho Pro</h2>
</div>

<div class="prose-block" markdown>

1. Plug Ucho Pro into the XLR input on your device
2. Turn on the phantom power
3. Set your gain to the appropriate level and enjoy!

[How to mount Uši →](../tips/mounting-usi.md)

!!! warning
    Using Uši with third-party cables is not covered under warranty. Uši XLR cables contain special circuitry to adjust phantom voltage for plug-in power voltage.

</div>
