# Electromagnetic FAQ

Questions about the electromagnetic listening instruments — Elektrosluch, Elektrouši, Elektroucho Pro, and Priezor.

### What is the difference between Elektrosluch, Elektrouši, Elektroucho Pro, and Priezor? { #difference-em }

Priezor, Elektroucho Pro, and Elektrouši are passive devices that need an external microphone preamplifier; Elektrosluch has one built in.

Priezor has a more "ambient" response and is more suitable for recording environments. Elektrosluch, Elektroucho Pro, and Elektrouši are more directional. Elektrouši and Elektrosluch are stereo.

### Can Elektrouši be mounted with a Uši mount? { #elektrousi-mount }

Yes, but only with the [Uši mount with the lyre](https://store.lom.audio/products/usi-microphone-mount-single) — others may damage the plastic case of the Elektrouši. Even with that mount, please be careful not to damage the plastic.
